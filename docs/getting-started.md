# Getting Started

Subspace is a collection of focused backend primitives. Use only the pieces you need.

## Prerequisites

- Node.js 22+
- pnpm 10+

## Install

```bash
pnpm install
```

## Run checks

```bash
pnpm lint
pnpm typecheck
pnpm test
```
